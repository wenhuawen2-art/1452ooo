# 向野界面字体层级核查

核查范围：当前小程序首页、行程、清单与穿搭、记账、我的、编辑面板，以及同源本地预览。以下是**已实现样式**，不是重新拟定一套会覆盖设计稿的全局字号。以 393px 宽设计稿为基准。

## 字体家族与字重

- 中文正文、标题和按钮：`Alibaba PuHuiTi 2.0`，系统无该字体时使用系统中文无衬线字体。
- 进度、账本和日期中的展示数字：`Konkhmer Sleokchher`，回退 Arial / 系统无衬线。数字不使用仿粗。
- 400 用于正文、辅助说明和展示数字；500 用于列表条目、金额旁文字和当前选项；600 用于日期、分组和表单标题；700 用于昵称、关键日期或金额；800 只用于首页旅行主标题等主视觉。

## 现行可见层级

|层级|典型位置|字号 / 行高 / 字重|说明|
|---|---|---|---|
|主视觉数字|清单进度、记账总额|64 / 64 / 400|数字字体；大金额缩到 44px，单位另排|
|旅行主标题|首页旅行名称|30 / 42 / 800|360px 窄屏缩到 28px，省略长标题|
|一级页面标题|清单标题、记账标题、我的昵称|24 / 34 / 400–700|昵称 700；记账标题按稿为 24px|
|日期与固定导航|行程日期、我的页标题、顶部问候|20 / 24–28 / 600|顶部品牌名 16 / 22 / 600|
|区块标题|出发准备、上午行程、清单分类、穿搭分组|18 / 24–25 / 600|主内容的第二层级|
|主要正文|清单条目、费用名称、选择和新增操作|16 / 22 / 400–500|表单输入同为 16px|
|时间与辅助|时间轴时刻、天气、日期辅助说明|14–15 / 20–24 / 400–500|时间轴时刻为 15px / 500|
|次要注释|行程备注、辅助标签|12 / 20–24 / 400|密集信息使用，不作为主要操作文字|

## 页面对应关系与例外

- 首页：旅行名 30/800，区块 18/600，卡片说明 14/400；倒计时与天气采用各自展示数字规格。
- 行程：问候 20/600，日期 20/600，时段与安排标题 18/600，时间 15/500，交通 14/400，备注 12/400。
- 清单与穿搭：页面标题 24/400，进度 64/400，分类和穿搭分组 18/600，条目 16/500，天气 14/400。
- 记账：账本标题 24，合计 64/400，明细名称 16/500，日期 14/400；大额数字根据位数降到 44px。
- 我的：导航标题 20/600，昵称 24/700，旅行名称 18/500（展开态 700），状态说明 12–14。
- 编辑面板：标题 20/600，字段输入 16，分组标题 18/600，保存按钮保持主操作层级。

## 审查结论

当前主流程在 12、14、16、18、20、24、30、44、64px 之间形成可辨的层级。旧组件样式中仍有 26/28/30/34rpx 的遗留规则，它们与当前设计稿页面同时存在；不应直接全局替换，否则会改变历史表单和空状态。下一次逐页设计对齐时，优先核对可见控件的最终计算样式，尤其是 12px 注释与 14px 辅助文字的对比度和长中文换行。

对应源码：`pages/index/home.wxss`、`route.wxss`、`list.wxss`、`expenses.wxss`、`forms-sheet.wxss` 和 `pages/profile/index.wxss`。设计稿节点及原始规格仍可在 `/design-review/` 的层级视图查看。
