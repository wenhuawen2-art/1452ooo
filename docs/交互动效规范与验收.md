# 向野：全系统交互动效

更新日期：2026-10-26。保留既有设计稿的配色、字号、尺寸和布局，用同一套节奏连接浏览、选择、编辑和保存。

## 参考方案

- [Ionic iOS navigation](https://github.com/ionic-team/ionic-framework/blob/main/core/src/utils/transition/ios.transition.ts)：参考有方向的页面切换和减速曲线；本项目模块切换位移减为16px、时长280ms，以适应高频切换。
- [Vaul drawer styles](https://github.com/emilkowalski/vaul/blob/main/src/style.css)：参考抽屉进入和退出、背景遮罩联动的方式，采用`cubic-bezier(.32,.72,0,1)`。
- [Radix animation / presence](https://www.radix-ui.com/primitives/docs/guides/animation)：参考退出时保留显示节点的生命周期处理。业务状态立即更新，退出副本不接受点击，200ms后清理。

采用上述交互思路自行实现，未引入React动画库或额外运行时依赖。网页和微信小程序分别使用适合各自渲染机制的实现。

## 时长和反馈

| 场景 | 表现 | 时长 |
| --- | --- | --- |
| 首页、行程、清单、记账切换 | 按底栏顺序轻微左右位移、淡入；底栏保持固定 | 280ms |
| 我的页面、路线概览进入 | 内容轻移、淡入；使用原有返回逻辑 | 280–300ms |
| 日期、行程分段、清单分段、记账分段 | 更新区域向上10px淡入；顶部保留位置 | 240ms |
| 底部表单进入 | 面板向上56px滑入，遮罩同步淡入 | 320ms / 220ms |
| 表单、详情、登录提示关闭 | 面板向下44px淡出，退出副本不可点击 | 200ms |
| 模板列表进入详情及返回 | 字段区轻移淡入 | 240ms |
| 更多菜单 | 从右上角轻微展开、淡入 | 180ms |
| 按钮、可点击卡片、日期、图标控件 | 按下等比缩到97%，降低少量透明度；松手恢复 | 100ms / 260ms |
| 鼠标悬停 | 放大到101%，细微亮度和边界反馈；离开恢复 | 180–260ms |
| 清单勾选 | 背景、边框更新；勾选轻微回弹 | 160–180ms |
| 准备进度和预算条 | 数值变化时进度平滑更新 | 400ms |
| 旅行卡片展开/收起 | 内容高度平滑展开和折叠，多个卡片独立 | 280ms |
| 输入框聚焦 | 蓝色边框与轻光圈 | 180ms |
| 保存/上传 | 禁用重复提交、加载指示、正在保存或上传文案 | 随实际请求结束 |

主要缓动为`cubic-bezier(.22,1,.36,1)`。交互不改变静态布局尺寸，触控区域保留原尺寸。拖拽表单使用既有内容高度和吸附规则，拖拽过程中不增加按压缩放。

## 实现位置

- `wechat-miniprogram/miniprogram/pages/index/interaction-motion.wxss`：共享过渡、按压、悬停、焦点和禁用状态。
- `wechat-miniprogram/miniprogram/utils/interaction-motion.js`：小程序切换状态、退出副本和计时器管理。
- `scripts/preview-motion.js`、`scripts/preview-client.js`：网页预览在整体DOM替换时识别真正变化的区域，避免每次输入或请求都重新播放全页动画。
- `pages/profile/index.wxml`：旅行卡片用可折叠容器保留完整展开和收起过程。

页面隐藏、减少动态效果、系统减少动态效果均停用相应动画。退出副本设置不可交互，快速重新打开时取消旧副本。业务数据提交与显示动画独立，保存失败仍由原表单保留草稿和错误提示。
