# 向野最新设计视觉规范

来源：MasterGo 200425698503069 / 166:04872，14张画板。393px 为基准。

## 间距与布局

- 顶部账号入口保持40×40px正圆：未登录显示人物图标，登录后显示账号头像，资料修改后同步更新。
- 一级页面底部采用176px加安全区的渐进模糊；正文在下、固定新增与底栏在上，末尾内容可滚到清晰区域。
- 输入表单默认随内容自适应；长内容只滚动正文，标题和保存固定。顶部横条可上拉/点击展开到可用全屏，下拉/点击收回。
- 表单底部保留16px加设备安全区；全屏状态仍避开微信胶囊。
- 393px 为核对基准；内容左右16px，主内容宽361px。
- 普通卡内边距12px；内层行/卡间距12或16px，以图层实测为准。
- 底栏高68px、左右16px、底部16px + 安全区。
- 固定新增按钮52×52px，右16px，距底栏外边缘28px。
- 顶部从胶囊下方开始；裸设计验收模式起点16px，手机模式按系统安全区计算。
- 圆角：条目12px、分组16px、主面板20px；胶囊全圆角。
- 字重400常规、500强调正文、600区块标题、700强强调、800首页旅行名。数字字体始终400。

间距使用：4 / 6 / 8 / 12 / 16 / 20 / 24 / 28 / 32 / 36 / 40 / 52 / 64 / 80px。不要将不同业务区块强行归一为同一个间距；逐节点数值在交互审查页可查。

## 背景与透明度

底色 #EDF1F5，正文 #001126。首页、行程、记账共用蓝白光感背景；清单与穿搭共用其背景实现。主要玻璃面板按新稿提高白色透明度，不能全局修改所有卡片。原稿逐层渐变、边框、透明度在审查页“节点层级”中完整展示。

## 审查方式与边界

打开 http://127.0.0.1:4193/design-review/ 。左侧切换14张画板，右侧可查看原稿、实现和叠加对照。选择层级节点查看原始字号、字重、行高、间距、圆角和透明度；“操作预览”进入原手机样机。截图采用本地模拟数据，不修改正式旅行。

当前是实现与对照材料，不能将截图已生成等同于所有像素已通过验收。浏览器与微信真机字体栅格、地图渲染、键盘和权限仍需单独核验。
