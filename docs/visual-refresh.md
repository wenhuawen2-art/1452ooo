# 向野：蓝白沉浸式重构交付

日期：2026-10-10。本轮仅本地代码与预览，未推送 GitHub、部署腾讯云或上传微信版本。

## 运行

运行 `npm run preview:mini`，打开 http://127.0.0.1:4191/ 。预览提供 360 / 390 / 430px 切换，以及已有旅行、游客、无旅行、归档和压力数据模式。所有编辑仅写入进程内模拟数据；刷新或切换模式可重建数据。`npm run test:preview` 需要预览服务正在运行。

预览直接解释同一套 WXML/WXSS，并在隔离环境运行小程序 Page 的校验、编辑与保存逻辑。地图为标注清楚的示意图；微信登录、真实定位、系统相册、云上传和分享不模拟为成功。

## 实现范围

- 六模块拆为独立视图片段；统一天空蓝、浅蓝与白色、深色正文与胶囊操作、轻薄六栏导航。移除旧山形装饰和临时主题覆盖。
- 今天显示旅行阶段、日期、准备进度、天气及路线。行程采用连续时间轴。清单保留完成项原位划线及独立复核。穿搭使用衣物网格与类型占位图。记账突出总支出，保留分账及统计。我的集中展示资料和旅行管理。
- 自定义顶部安全区；长表单使用独立原生 editor 页面，短操作保留底部面板。通过 EventChannel 复用原页面的保存、上传与校验方法，不复制云接口。
- 行程、住宿、清单条目、费用增加详情入口。整套穿搭与单件快捷编辑保留，已有整套编辑无新增衣物按钮。
- 未保存退出确认、字段错误、失败草稿保留、保存防重复；模块保留滚动位置、日期及筛选。提供减少动态效果设置，隐藏时暂停环境动画。
- 未修改公共云接口、业务数据结构或迁移历史数据。

## 验证结果

- `npm test`：68 / 68 通过。
- `npm run test:preview`：六模块 × 四状态、详情进入编辑、草稿退出、失败保留、重试保存、无旅行及归档守卫通过。
- 浏览器实际操作：修改行程、继续编辑、保存失败显示草稿、添加行程后保存返回成功；整套编辑显示全部衣物且不提供新增衣物按钮。
- 360 / 390 / 430px 六模块压力数据页面均无文档横向溢出。压力数据含长标题、大金额、长清单和多件无照片衣物。检查数据见 `output/redesign/layout-checks.json`。
- 微信官方 WXML / WXSS 编译器编译通过；`git diff --check` 通过。
- 截图见 `output/redesign/`：today / route / list / outfit / expenses / people，以及 event-editor / outfit-editor / garment-editor。浏览器截图为 390 × 700 可视区域，不是微信真机截图。

## 尚未完成的原生验收

微信开发者工具自动化连接成功，但没有可用页面实例，读取页面元数据返回 rawPath 错误；桌面窗口读取也受系统访问限制。因此独立编辑子页的真机切换、系统返回确认、软键盘遮挡、设备安全区、原生图片上传、登录授权、腾讯地图及云端保存尚未真机验证。浏览器和模板编译结果不能替代这些检查。

本地预览只能验证共享模板和业务交互。上线前需在微信开发者工具恢复后，再用测试账号和测试旅行验证上述原生能力及 Android/iOS 设备，不使用正式旅行作增删改验收。

## 旅行碎片加载动画（2026-10-10）

加载状态改为 24 个本地旅行插画碎片组成的环绕动画：山野、海岸、露营、地图与票根。三条错位椭圆轨迹，8.1 秒无缝循环；通过尺寸、倾角、透明度和前后排序表现景深。中心固定品牌，底部固定状态文字，不显示虚假百分比。

仅真实 `loading` 状态显示；请求完成后立即卸载，不添加人为等待。隐藏页面暂停；减少动态效果时保持静态碎片布局。没有额外图片网络请求，也不读取用户旅行照片。

独立演示：http://127.0.0.1:4191/?mode=loading 。演示为了观察动画会持续播放，切换左侧状态可返回正常页面；正式加载页由请求完成状态关闭。

验证：68 项测试、原生模板与样式编译通过。浏览器确认碎片位置连续变化；原生真机流畅度仍待设备验证。
