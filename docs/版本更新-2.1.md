# 向野 2.1 更新说明

## 微信开发工具上传说明

五栏导航与穿搭独立页面上线；优化首页、行程、清单、穿搭和记账界面，完善按模块新增、空状态及交互反馈，修复记账首次加载与日期定位。

## 本版更新

- 底部导航统一为首页、行程、清单、穿搭、记账。穿搭成为独立模块；行程、清单、穿搭和记账在页面右下角提供各自的新增操作，住宿与票据分段不显示悬浮新增按钮。
- 首页可直接编辑出发和归来日期；“我的”旅行卡提供切换旅行入口。
- 调整各模块标题、日期带、间距、底部控件和空状态插图；保留旧加载页，同时加入新版旅行插画加载页。
- 完善清单关键项、模板导入、穿搭编辑及费用展示等页面交互；修复记账页首次进入时金额与日期未及时显示的问题。
- 压缩小程序图片与 SVG，保留原始设计素材，确保微信开发工具的代码包符合上传体积限制。

## 本地验证

- 全仓构建与自动化测试：108 项通过。
- 微信开发工具编译预览成功；在模拟器检查了五个主模块及住宿与票据分段，未发现脚本异常。
- 模拟器检查不等于真机验收；微信上传后仍需在手机上检查不同机型的安全区、字体和图片表现。
