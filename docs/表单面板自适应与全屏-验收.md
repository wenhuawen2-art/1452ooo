# 表单面板：自适应高度与全屏展开

更新日期：2026-10-25。

## 统一规则

- 默认按实际字段、标题、操作区的内容计算高度，不再固定为78vh，也没有强制的240px最小高度。
- 只有长表单达到默认高度上限时，正文区域才开始滚动；标题、关闭按钮和保存操作留在可见区域。
- 底部留16px空白，并叠加设备底部安全区。键盘出现时不重复叠加底部安全区。
- 顶部36×4px横条支持上拉展开、下拉收回；也可以点击切换，避免只能靠手势操作。
- 展开到可用全屏，仍避开微信顶部胶囊和状态区；“我的”表单和其他模块共用相同计算。
- 拖动中实时跟随，松手吸附。取消拖动恢复原状态，向下拖动不会直接丢弃或关闭草稿。
- 切换类目、增删衣物、显示校验错误等内容变化后重新测量；当前表单的展开状态保持不变，新表单重新使用自适应高度。
- 保存、上传、校验、未保存退出提示和权限规则沿用原有实现。

## 实现与验证

小程序与本地网页复用 `utils/form-sheet.js` 的高度和手势吸附规则。小程序使用实际字段尺寸测量，网页使用DOM尺寸与ResizeObserver，不按字段数量估算高度。

393×852裸画板示例：新建分类约283px，创建旅行约556px，长记账表单初始约665px；展开后占用可用全屏。原苹果样机中全屏上沿为104px，避开微信胶囊。

- 360、390、393、430px四种宽度，15类表单共60个浏览器场景通过。
- 验证了横条点击展开/收回、鼠标模拟上拉/下拉、草稿保留、全屏切换类目后保留展开状态。
- 验证了未保存退出提示、“继续编辑”、模拟300px键盘后的保存入口可见。
- 原苹果手机样机中的资料表单通过，展开后保留原页面背景，且不遮挡顶部微信控件。
- 全仓构建及90项测试通过，新增内容高度、限高、键盘、安全区、拖动吸附、取消拖动、新表单状态重置回归测试。
