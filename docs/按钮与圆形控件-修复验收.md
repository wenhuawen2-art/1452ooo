# 按钮与圆形控件修复验收

日期：2026-10-25。仅本地代码和预览，未上传或发布。

## 问题与修复

1. 旧的全局 `button { min-height:44px }` 覆盖了新稿40px头像按钮的高度，实测变为40×44px；无旅行页头像在不同宽度下甚至变为34.55×44px。现在固定为40×40px，并限制flex收缩及最小/最大尺寸。
2. 日期带内部空间不足时，6px圆点参与flex收缩，实测变为6×3px。现在圆点固定6×6px，选中日期的内边距扣除边框占用，保持日期卡102px总高度。
3. 圆形关闭按钮统一40×40px；底栏入口固定52×52px；头像、编辑、更多、主题圆形控件不参与弹性挤压。
4. 图标图片保持原尺寸、不参与flex收缩；无旅行页顶部辅助文案在空间不足时截断，避免挤压头像。
5. 头像、关闭和编辑按钮使用透明扩展区域保留至少44px点击范围。浏览器实际点击了头像和关闭按钮视觉边界之外的区域，仍能正常打开/关闭页面。

修复集中在 `wechat-miniprogram/miniprogram/styles/control-geometry.wxss`，由首页/模块、编辑页和“我的”页面共同复用。未改旅行数据、保存方法或权限规则。

## 验证范围

- 360 / 390 / 393 / 430px四种宽度。
- 220个页面、表单、详情、邀请、管理、确认框与路线面板组合：圆形控件宽高一致，无页面横向溢出。
- 16个超长昵称、旅行名、穿搭标题场景：头像、编辑、更多、底栏和日期圆点尺寸保持稳定。
- 首页、行程、清单、记账的4个头像扩展点击区域可进入“我的”；资料弹窗关闭按钮扩展区域可关闭。
- 详情、衣物类型、资料、记账表单关闭按钮均为40×40px。
- 全仓构建及85项测试通过。

欢迎页的装饰路线弧线有意使用椭圆外形，未将其当成圆形按钮修改。长条胶囊和日期竖卡也保持原设计比例。
