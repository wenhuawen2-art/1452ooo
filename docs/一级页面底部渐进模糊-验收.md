# 一级页面底部渐进模糊

2026-10-25，本地更新，未上传或发布。

## 视觉与层级

首页、行程（含住宿票据）、清单、穿搭、记账，以及游客和无旅行一级页面统一加入底部渐进模糊。高度176px加设备底部安全区，从透明开始，采用2 / 6 / 12 / 20px分层模糊，并叠加与页面底色一致的浅色渐变；不支持滤镜时仍有渐变淡出的基础效果。

层级为正文 → 模糊层（28）→ 固定新增按钮（29）→ tabbar（30）→ 弹窗。新增按钮移入统一的底部控件层，避免被模块内部的独立层叠上下文压到模糊层下面。新增调用仍使用原有方法和权限守卫。

模糊层不接收点击或滚动。表单、详情、地图、登录、结算和操作菜单打开时暂时隐藏，不影响这些界面的文字与操作。“我的”独立子页面没有tabbar，未添加此效果。

所有末尾内容增加对应滚动留白，可完整滚到模糊区上方查看；固定新增与tabbar的28px间距保持不变。页面隐藏时不绘制效果，没有新增环境动画。

## 验证

- 360 / 390 / 393 / 430px四种宽度，带34px底部安全区的40个页面状态通过：滤镜与遮罩生效，无横向溢出，最后内容可滚到清晰区域。
- Android 360×800、底部安全区0，10个页面状态通过。
- 4个新增入口仍打开原编辑器；游客登录守卫、归档只读、无旅行导航通过。
- 验证模糊区内正文可点穿到详情，导航与新增按钮位于效果之上；弹窗和操作菜单不被再次模糊。
- 全仓构建与91项测试通过，包含移出模块后的浮动新增入口关闭旧菜单的回归。
